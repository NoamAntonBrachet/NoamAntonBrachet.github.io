Guide d'installation d'un serveur web sur machine virtuelle

Langage / OS Linux
Groupe Seul
Durée 1 mois

Description

Réalisation d'un guide complet pour installer un serveur web sur une machine virtuelle Linux et le configurer correctement, de l'installation du système jusqu'à la mise en ligne d'un site.

Installation et configuration d'un serveur web sous Linux en machine virtuelle, rédaction d'un guide pas à pas documentant chaque étape : installation de l'OS, configuration réseau, mise en place du serveur et tests de fonctionnement.
