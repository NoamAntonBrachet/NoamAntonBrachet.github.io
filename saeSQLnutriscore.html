Création d'une base de données à partir de statistiques Nutriscore

Langage PostgreSQL
Groupe 2 personnes
Durée 1 mois

Description

À partir d'un jeu de données réel sur les Nutriscores de produits alimentaires, conception et peuplement d'une base de données relationnelle permettant d'analyser et visualiser ces statistiques.

Ce que j'ai fait

Importation et nettoyage des données brutes, modélisation du schéma relationnel adapté aux statistiques Nutriscore, création des tables sous PostgreSQL et rédaction des requêtes d'analyse et de visualisation des données.

Technologies

PostgreSQL SQL
